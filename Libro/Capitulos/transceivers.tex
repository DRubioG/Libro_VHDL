\chapter{Alta velocidad}

Las FPGAs además de los elementos básicos como
CLBs, memoria integrada, etc.
También incorporan un elemento interesante que son 
líneas de alta velocidad para transceivers.

Las líneas de transceivers se sirven de un concepto tecnológico que se 
basa en desafasar un reloj de entrada para utilizar los flancos
de subida/bajada para inyectar un dato en una línea.
